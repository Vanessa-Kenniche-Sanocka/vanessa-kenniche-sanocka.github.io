PRISME : semantic search engine over the public corpus of the French Court of Audit, available to audit teams, magistrates and domain experts

End-to-end RAG pipeline over ~35,000 Court publications (~2M indexed paragraphs), from table-of-contents extraction to natural-language sourced answer generation. Fourteen-stage modular chain: two-pass semantic chunking combining LLM-based TOC extraction and fuzzy split via TOC-zone fingerprint (original idea designed to bypass the classic indexing pitfalls of long PDFs), breadcrumb contextual enrichment inspired by Anthropic’s Contextual Retrieval, dual indexing in Elasticsearch (textual BM25 + vectorial KNN HNSW over Qwen3-8B embeddings), hybrid retrieval via RRF, MMR diversification, cross-encoder Qwen3 reranking, Mistral generation gated by a refusal threshold calibrated against hallucinations. Evaluation through manual gold standard and RAGAS, ablation testing at every stage. Next.js / FastAPI interface, multi-service Docker deployment in a sovereign air-gapped environment (Nexus registry, multi-target justfile, dual-VM SSH, offline builds, feature flags in production). Scientific paper in conference format (ACL/IEEE) under writing on the methodological contributions. Python FastAPI Next.js ElasticSearch RAG Qwen3 Mistral Docker Nexus Air-gapped MLOps LaTeX

Wikam : knowledge graph exposed to an AI agent via Model Context Protocol, alternative to classical RAG for the Court’s structured institutional memory

Design of an MCP server wrapping the internal wiki to let an LLM agent navigate the institution’s procedural memory (audit organization, investigation flow, magistrate / verifier / counter-rapporteur roles) instead of receiving the raw markdown. The model accesses tools for title search, page retrieval, hierarchical traversal and neighborhood lookup, and invokes them on demand. The approach is relevant when the content is already well-chaptered and where classical RAG chunking would introduce noise. Sequenced adoption strategy: NetworkX graph as a POC, plugging in PRISME’s embeddings infrastructure for hybrid RAG, full-entity-extraction GraphRAG envisaged only as a last resort. Python MCP NetworkX BookStack LLM Agent Knowledge Graph

Asynchronous LLM pipeline for identifying and structuring the “recommendations” sections of reports, never extracted systematically before.
