Plan étape par étape (du + simple au + complexe)

Chaque étape produit un site qui marche — tu valides, puis on passe à la suivante.

  1. Nettoyage sans risque visuel (ce qu’on fait maintenant) - Supprimer images/fond3.jpg (orphelin) - Supprimer le # orphelin dans les 3 qmd + les — séparateurs - Supprimer la colonne espaceur de 10%, passer left/main en 30/70 - Clarifier le .gitignore (statu quo sur docs/, documenter) - But : un point de départ propre, sans toucher au rendu.
  2. Migrer le contenu vers des classes CSS (toujours même look) - Remplacer tous les par des divs Pandoc ::: {.role-context}, ::: {.justify} selon cas - Déplacer le bouton “Télécharger le CV” vers une classe (plus de
    ) - But : le HTML devient stylable proprement, plus aucune bataille avec l’inline.
  3. Introduire un système de tokens dans styles.css (même look) - Variables –space-, –duration-, –ease-*, –text, –surface, etc. - Remplacer les valeurs en dur par les tokens - But : le thème clair/sombre et le glass viendront “gratuitement” ensuite.
  4. Passer le layout en CSS Grid (fin des margin: -200px) - grid-template-columns: minmax(280px, 340px) minmax(0, 1fr) + gap - Sidebar position: sticky - But : responsive robuste, base solide avant de redesigner.
  5. Thème clair/sombre (nouveau mais isolé) - data-theme sur , init localStorage dans (anti-flash), toggle dans scripts.html - Deux palettes complètes (sans toucher au visuel global pour l’instant) - But : capacité en place avant la refonte visuelle.
  6. Refonte visuelle (le gros morceau) - Google Fonts (Inter + Fraunces) en preload non-bloquant - Cartes glass (backdrop-filter, radius 20px, shadows étagées) - Fond image + voile sur body (pas de ::before) - Tags en pills, animation de reveal CSS pure - But : la vibe “éditoriale senior” de refonte.md.
  7. Scripts propres + scroll-spy IntersectionObserver, accessibilité (:focus-visible, prefers-reduced-motion), @media print pour CV imprimable.
